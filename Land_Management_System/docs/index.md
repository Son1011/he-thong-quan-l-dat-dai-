## Tài liệu hệ thống (MVP) — mục lục

Các file dưới đây là bản tách nhỏ từ `docs/system-spec.md` để đọc dễ hơn, dùng cho báo cáo/hand-off.

- `docs/01-overview.md`: tổng quan hệ thống, mục tiêu, phạm vi MVP
- `docs/02-database.md`: database schema (MySQL), bảng/field/quan hệ, ràng buộc, dữ liệu seed
- `docs/03-user-stories.md`: user stories + acceptance criteria theo vai trò
- `docs/04-api.md`: danh sách endpoint + request/response + quyền truy cập
- `docs/05-diagrams.md`: Mermaid diagrams (ERD, state, sequence, flow)
- `docs/06-frontend.md`: UI/UX, role-based UI, các trang, luồng thao tác, chữ ký
- `docs/07-backend.md`: kiến trúc Java Spring Boot, auth/JWT, scope dữ liệu, upload file, thống kê
- `docs/08-deployment.md`: backend Java local run, frontend Vite, hướng deploy hiện tại
- `docs/09-security-and-upgrades.md`: bảo mật hiện tại (MVP) và hướng nâng cấp
- `docs/10-requirements.md`: yêu cầu chức năng/phi chức năng (FR/NFR) cho đồ án
- `docs/11-use-cases.md`: use cases theo actor + luồng chính/phụ
- `docs/12-architecture.md`: kiến trúc (component/deployment diagram)
- `docs/13-testing.md`: kế hoạch kiểm thử + test cases mẫu

> Nếu bạn chỉ muốn đọc 1 file “full”: xem `docs/system-spec.md`.
